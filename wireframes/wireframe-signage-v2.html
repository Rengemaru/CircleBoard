QRだけは 2〜3m に届かない。3m から読める QR は 300mm（520px 相当）で、カードには入らない。 この案は「遠くから残り日数とタイトルを読み、気になったら1〜2m まで歩み寄ってQRを読む」という動線を前提にしている。 この前提を仕様に明記することが、この案の受け入れ条件のひとつ。

実装に写すとき

このファイルの cqw の数値は、そのまま SignagePage.tsx の su(n) の n になる。 su(n) は 16:9 のとき n vw と等しく、キャンバス幅の n% に一致するため。 例：.ec.c4 .ec-cd{font-size:3.2cqw} → COUNTDOWN_SIZE.compact = su(3.2)。
ゾーンの高さ配分を変えている。.ev-zone の flex を 1.35 → 1.75 に上げた。 文字を大きくすると 2×2 のカードが高さ不足になるため、余っていたプロジェクト枠（実測で1枚あたり50px余剰）から回す。
タイトルは1行で切れる。3〜4件表示のカードは幅900px・文字48pxで、日本語なら約14文字で … になる （上の S1 で実際に切れている）。2行にする余地は高さに無い。 長いタイトルを最後まで出したいなら、4件表示そのものを諦めるしかない。
